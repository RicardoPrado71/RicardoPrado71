## 🧑‍💻 About me

I've been working in **software development for 5 years**, building products end to end: database modeling, APIs, web front-ends and mobile apps. My day-to-day stack is **TypeScript, React, Next.js, Node.js/NestJS, React Native and Java/Spring Boot**, and I focus on delivering solutions that solve real business problems.

Over these years I've worked on systems across many industries and built solid experience in:

- 🏢 **Multi-tenant architecture**: many clients in a single application, with data isolation, permissions and per-company customization
- 🔐 **Authentication & security**: JWT, OAuth/NextAuth, role-based access control, password hashing and rate limiting
- 💳 **Payments**: payment gateway integration (Mercado Pago) and checkout flows
- 🔗 **Integrations**: REST APIs, Supabase, real-time communication with WebSockets and offline sync in mobile apps
- 🧾 **Business systems**: ERP, POS, scheduling and time tracking
- 🐳 **Deployment**: Docker, Vercel and managed PostgreSQL databases

I value typed code, simple architecture and great user experience. Always learning and open to new challenges. 🚀
